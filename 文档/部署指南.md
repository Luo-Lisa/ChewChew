# 城市鸟类科普网页 - 部署指南

## 🚀 方案一：最快预览（无需注册）

### Netlify Drop（推荐，1分钟搞定）

1. 访问 https://app.netlify.com/drop
2. 打开项目文件夹 `e:\TRAE\chewchew` 中的所有文件（index.html, styles.css, script.js）
3. 直接拖放到网页的拖放区域
4. 等待几秒钟，即可获得一个可访问的链接

### GitHub Pages（需要 GitHub 账户）

## 📦 方案二：使用 Vercel（推荐）

### Vercel 部署步骤：

1. 访问 https://vercel.com
2. 使用 GitHub/GitLab 登录
3. 创建新仓库
4. 将项目文件上传到仓库
5. 导入仓库到 Vercel
6. 自动部署完成

## 🐙 方案三：GitHub Pages

### 步骤：

1. 创建 GitHub 账户
2. 创建新仓库
3. 上传项目文件
4. 启用 GitHub Pages（Settings > Pages > Source 选择 main 分支
5. 几分钟后即可访问

## 💻 本地临时预览

如果你有 Python，可以运行：

```bash
# Python 3
python -m http.server 8000
```

然后访问 http://localhost:8000

或者使用 Node.js：

```bash
npx serve
```

## 📁 需要的文件

确保上传以下文件：

- index.html
- styles.css
- script.js
- documents/ 文件夹（可选，文档）
